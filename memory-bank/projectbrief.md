# Project Brief: Simply Droplets

## Core Goal
Create a 3D droplet-based granular synthesis audio plugin that runs as VST/CLAP in a DAW.

## Concept Overview
Simply Droplets extends granular synthesis by using "droplets" instead of traditional "grains":
- Droplets are positioned in 3D audio space
- Droplets have time-warping characteristics that affect playback
- Droplets can have dynamic movement along paths

## Target Platform
- macOS

## Key Technologies
- Rust programming language
- `nih-plug` framework for plugin development
- `nih-plug-iced` for the user interface

## Implementation Scope
1. Core droplet processing engine
2. Basic parameters and simple distributions
3. Simple UI controls
4. 3D positioning
5. Advanced time-warping
6. Full UI with curve editors
7. Future extensions
