# Project Brief: Granular VST

## Core Goal
Create a VST/CLAP audio plugin that functions as a granulator effect.

## Target Platform
- macOS

## Key Technologies
- Rust programming language
- `nih-plug` framework for plugin development
- `iced` GUI toolkit for the user interface

## Initial Scope
- Set up the basic project structure.
- Integrate `nih-plug` and `nih-plug-iced`.
- Establish a minimal working plugin instance (compiles, loads in a DAW).
- Basic granulator functionality will be implemented later.
