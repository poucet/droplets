# Product Context: Granular VST

## Problem Solved
Provides musicians and sound designers with a tool to create complex textures and soundscapes through granular synthesis, integrated directly into their Digital Audio Workstation (DAW).

## How it Works (High-Level)
The plugin will take an incoming audio signal, chop it into small pieces ("grains"), and then manipulate and replay these grains based on user-controlled parameters (e.g., grain size, density, pitch, position).

## User Experience Goals
- Intuitive user interface built with `iced`.
- Real-time manipulation of granular parameters.
- Stable performance within various DAWs on macOS.
